CLI modes, build profiles, and compile flags

Command-line invocation modes, release build profiles, and compile-time -D feature flags.

CLI invocation

CommandBehavior
boomkat <file>Evaluates <file> as an ES module (strict mode). Supports .js, .mjs, .ts, .tsx, .jsx.
boomkat --script <file>Evaluates <file> as a classic script (sloppy unless "use strict" is present; .ts is always strict).
boomkat_debug -c <file>Prints bytecode disassembly when built with -D TRACE_VM (just build-trace).

Build profiles

ProfileApprox. sizeIncluded features
boomkat~2.2 MBDefault CLI; modern ECMAScript, TypeScript/JSX, small English Intl.
boomkat-full-icu>4 MBFull bundled Intl locale data, Collator with tailorings, and Temporal.
boomkat-slim~1.5 MBExcludes TypeScript, JSX, Temporal, Intl, BigInt, Proxy, and other optional features.
boomkat-tiny~700 KBReduced ECMAScript set, no parser or compiler; executes precompiled .bkbc bytecode only.

Runtime and VM flags (-D)

FlagEffect
NONANBOXDisable NaN-boxing; use 16-byte tagged union TVal.
THREADED_DISPATCHEnable direct-threaded VM dispatch (enabled in default CLI).
SMALL_VMUse size-optimized VM dispatch loop.
STRICT_ONLYCompile out sloppy-mode support.
BYTECODE_ONLYOmit parser and compiler; execute precompiled bytecode images only.
BYTECODE_GENERATOREnable bytecode image serialization.

Optional feature flags (-D)

FlagEffect
PRINT / CONSOLERegister global print / console.
INTL / INTL_FULL / INTL_COLLATOREnable native Intl, full bundled locales, and Intl.Collator.
TEMPORALEnable Temporal namespace.
NO_TYPESCRIPT / NO_JSXOmit TypeScript stripping / JSX lowering.
NO_BIGINT / NO_PROXY / NO_REGEXPOmit BigInt, Proxy/Reflect, or RegExp.
NO_BUFFERS / NO_COLLECTIONS / NO_WEAKREFOmit ArrayBuffer/TypedArray, Map/Set, or WeakRef/FinalizationRegistry.
NO_MODULE_LOADING / NO_SHARED_MEMORYOmit ESM loading or SharedArrayBuffer/Atomics.

Diagnostics and verification flags (-D)

FlagEffect
TRACE_VMEnable bytecode disassembly and VM tracing.
OP_PROFILE / GC_PROFILEEnable opcode or GC profiling.
HEAP_VERIFY / GC_VERIFY / GC_STRESSValidate GC roots, check incremental GC invariants, or collect at every allocation.
SCAN_POISON / POOL_BYPASSPoison freed storage or bypass allocation pools for AddressSanitizer.
