how-to guide

Build a custom profile or tiny bytecode binary

Trade language features and internationalization data for binary size, or precompile bytecode for the parser-less boomkat-tiny runtime.

Toggle Intl, Collator, and Temporal

Pass feature overrides directly to just build:

# Minimal Intl (none) and no Temporal
just build boomkat --intl=none --temporal=false

# English Intl formatting + Unicode segmentation
just build boomkat --intl=small

# Small Intl plus root collation
just build boomkat --intl=small --collator=true

# Full bundled Intl data, Collator, and Temporal
just build boomkat-full-icu

# Full bundled Intl data without Collator
just build boomkat-full-icu --collator=false

Precompile and run bytecode with boomkat-tiny

boomkat-tiny omits the parser and compiler and runs only precompiled .bkbc images.

  1. Build the tiny runtime and its companion bytecode compiler: 
    just build-tiny
  2. Compile a JavaScript file to a bytecode image: 
    ./out/boomkat_tiny_compile --compile program.bkbc program.js
  3. Execute the image on the tiny runtime: 
    ./out/boomkat_tiny program.bkbc

Build diagnostic variants

  • Unoptimized debug build: just build-debug boomkat
  • Bytecode disassembly and VM trace: just build-trace && ./out/boomkat_debug -c file.js
  • GC-stress build (collects on every allocation): make out/boomkat_gc_stress && ./out/boomkat_gc_stress file.js
  • Alternate 16-byte tagged union value representation: just build-nonanbox
