# Bounded WIDE continuation liveness and property layout

The compiler now shares decoded register uses, definitions and call windows for a bounded (512-word maximum) continuation analysis. It validates original bytecode boundaries and branch targets, rejects unsupported/exception control flow, and computes a fixed point for backedges. The existing loop SSA only uses it for a function with WIDE bytecode, identity slot mappings and no eval, mapped arguments, suspension or other unsupported behavior. Other cases keep conservative recovery. This is not cyclic function SSA or a WIDE function compiler.

On the 296-word focused fixture, bytecode shows the low-register loop followed by a WIDE 261-argument call. Conservative exit recovery kept all 64 slots; decoded CFG liveness requires r0 and r2. The measured ARM64 SSA region shrinks 1288 to 1200 bytes, 322 to 300 instruction words, with static loads/stores 88 to 78 including cold exits. Actual release execution completed 150,535 and 60,663 native iterations for dead and live continuation cases; the fixture checks effects and results. The before/after bytecode, disassembly and native diagnostics are alongside this report. An instrumented full Octane run recorded no accepted WIDE continuation event, so this does not establish an Octane speedup.

During validation an existing unrelated JIT correctness fault caused 29 Array Test262 differential failures. A constructor property's second GETPROPC was polymorphic; its native inline slot address incorrectly assumed every object class places inline slots immediately after HObjectBase. Function-class objects instead put the slots after their own payload. The polymorphic path now obtains the byte offset from GcBits.inline_words, and inherited-property paths use the recorded owner's inline offset. The previously failing reduced Test262 case passes under JIT stress and ARM64 ASan. Language expressions, statements, and built-ins/Array Test262 differential suites match between interpreter and JIT. Local, Rosetta and module differential runs match (local status 1 in both because this default build lacks Intl/Temporal). The WIDE fixture and embedding checks passed ARM64 ASan and x86-64; a slim build passed.

The next responsibility remains shared cyclic CFG/SSA with exact recovery and actual workload coverage. The 50,000 full Octane target is not achieved; the last verified aggregate is approximately 6,550.
