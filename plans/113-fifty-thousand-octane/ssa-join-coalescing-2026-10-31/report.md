# SSA join coalescing

The preceding CFG change admits Crypto's `nbits` as an inlined SSA leaf. Its five diamonds keep both `x` and `r` alive at successive joins. The allocator assigned separate homes to each incoming value and join, yielding 11 spills in the captured `nbits` graph. The ARM64 code stored and reloaded both merged values before the next shift. Pure-register, in-place direct SSA can instead give a join the same register as a dying incoming value of the same representation, provided no other live value overlaps and no other parallel phi copy still needs that register on any incoming edge. Identical-location copies then emit nothing. The rule does not extend to loop phis, non-direct regions or spilled inputs.

The first coalescing prototype was wrong: on a value-swapping diamond one edge overwrote a register before another phi copied it. The retained rule explicitly checks every incoming edge and other phi source; the failing input and diagnostics are preserved in `rejected-parallel-copy.txt`. The regression fixture covers the swap, all branch combinations, numeric representations and edge values, signed zero, strings, coercion with side effects, and a callee mutated during coercion. It passes Node, interpreter, normal JIT and JIT stress; ARM64 ASan and x86-64 normal/stress fixture runs also pass. Thirty generated branch-and-swap functions produced the same result in Node, the interpreter and stress JIT. Instrumented normal-JIT runs executed 936 SSA completions per function. ARM64 ASan and x86-64 embedding pass. Local, Rosetta, module and selected Test262 language expressions/statements and built-ins/Array interpreter-vs-JIT verdicts match. Default local status 1 matches the no-Intl/Temporal interpreter build.

The captured `nbits` graph falls from 11 spill slots to 5; the first ARM64 leaf falls 980→860 bytes, 245→215 static instruction words and 66→37 static loads/stores, including cold paths. Its actual false branch no longer writes both merged values and reloads them for the next shift. The before/after disassemblies and allocator diagnostics are retained. A separate attempt to eliminate dead bytecode-register joins did not change the captured `nbits` or branch-fixture native code and was not retained.

Seven alternating release pairs on a 10-million-call five-diamond fixture give 774→750 ms median (-3.1%). The extracted Crypto leaf over mixed uint32 inputs gives 946→943 ms, but approximately half of its entries fall back. A restricted nonnegative-input run completes 9,999,938 native leaves and gives 376→374 ms (-0.53%); this is not a strong throughput gain. Five paired minis: code-load 154→154 ms, zlib 3733→3726, Mandreel 552→555, TypeScript 1233→1225, Crypto 164→164, Gameboy 275→276, DeltaBlue 89→89. Seven-pair additional medians: RayTrace 160→160, Box2D 199→199, Navier–Stokes 191→192, Splay 110→110 and Earley–Boyer 154→153. Raw pairs are retained. The full Octane suite was not rerun for this allocator change; the prior three-pair full median was 6,565, and 50K remains open.
