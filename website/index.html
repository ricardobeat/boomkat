A small, quiet interface

Pico CSS v2, set in iA Writer Quattro at 15px, wearing a 1985 palette.

Everything below is stock Pico markup — no extra classes beyond the palette swatches and the stripe rule. The only changes are the root font size, the typeface stack, and the custom properties that carry the colors.

Typography

Body copy runs at 93.75% of the browser default, which lands at 15px and stays there across every breakpoint. Quattro is a duospaced face: it keeps the even rhythm of a monospace while letting narrow letters like i and l breathe, so long paragraphs stay readable in a way true monospace rarely manages.

Heading level three

Inline flourishes still work — bold, italic, highlighted, struck, inserted, Ctrl + K, and a tooltip link.

What is duospaced type?

A monospace grid with a few characters allowed to be half-width. iA built Duo and Quattro around the idea; Quattro relaxes it furthest.

Why disable dark mode?

The page pins data-theme="light" on <html>, which outranks Pico's prefers-color-scheme rules.
