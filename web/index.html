boomkat

A tiny, fast JavaScript engine with modern features. Runs TypeScript and JSX without a build step. Written in C3.

read the docs open in github (opens in a new tab)

features

ES2026
native ESM, top-level await, proxies, modern built-ins
TypeScript
run .ts, .tsx and .jsx files directly
Intl
Temporal and full internationalization with the full-ICU build
footprint
2 MB default, tunable down to ~700 KB
speed
20–40% faster than QuickJS, ~10x Duktape, <2 ms startup
test262
53,240 / 53,578 passing (99.3%)

architecture

compiler
flat AST, type stripping, register-based bytecode
optimizer
constant folding, peephole, fused ops, inlining
vm
direct-threaded dispatch
gc
incremental, generational, string refcounting
jit
sljit backend, in development
embedding
C ABI, static and shared library

build profiles

boomkat
default CLI, English Intl
full-icu
complete Intl and Temporal, 4 MB+
slim
~1.5 MB, no TS/JSX, Intl, BigInt, Proxy
tiny
~700 KB, precompiled bytecode only
